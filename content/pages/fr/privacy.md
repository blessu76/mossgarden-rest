**Reprendre sur vos autres appareils** : pour reprendre votre progression (jardin, réglages, historique) sur les appareils utilisant le même identifiant Apple, les données sont enregistrées dans votre propre iCloud (stockage clé-valeur). Ces données ne sont pas envoyées aux serveurs de notre société ; si vous désactivez iCloud, elles restent uniquement sur votre appareil.
